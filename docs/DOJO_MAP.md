# Dojo Map — DORA capabilities to learning modules

Use this table to match an implementation task to the most relevant prerequisite module in the Fawkes Dojo. The table is ordered by DORA capability number so it is easy to navigate from the repo’s task framing. Belt labels are intentionally not strictly monotonic because this map prioritizes capability matching over belt progression.

| AI Capability 5 — Working in small batches | Yellow Belt | Module 05 — CI fundamentals | https://paruff.github.io/fawkes/dojo/modules/yellow-belt/module-05-ci-fundamentals/ |
| AI Capability 6 — User-centric focus | Black Belt | Module 17 — Platform as product | https://paruff.github.io/fawkes/dojo/modules/black-belt/module-17-platform-as-product/ |

Note: AI Capabilities 1 and 3 intentionally share the same prerequisite module (White Belt / Module 01) because both are foundational context-and-stance topics. Capability 6 is listed before Capability 7 to keep the table aligned to DORA capability order rather than a strict belt ladder.

Use the nearest prerequisite module before implementing a capability, then move back to the repo’s `AGENTS.md` guidance and issue acceptance criteria.
