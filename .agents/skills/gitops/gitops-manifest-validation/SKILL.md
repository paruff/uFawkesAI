# Skill: GitOps Manifest Validation

> **Load trigger:** `"load gitops-manifest-validation skill"` > **DORA:** Cap 4 (CI/CD Automation)
> **Token cost:** Low

## Purpose

Ensure all Kubernetes manifests generated by OBS or PIPE are valid, secure, and production-ready.

## Responsibilities

- Validate Kustomize overlays
- Validate Helm charts (if present)
- Validate schema correctness (kubeconform)
- Validate image tag format and digest correctness
- Validate environment overlays (dev/stage/prod)

## Inputs

- GitOps repo
- Rendered manifests
- Environment overlays

## Outputs

- `manifest-validation.json`
- `manifest-diff.txt`

## Sub-Skills

| Skill | Purpose |
|-------|---------|
| `gitops-manifest-validation/kustomize` | Kustomize overlay validation |
| `gitops-manifest-validation/helm` | Helm chart validation |

## Validation Rules

- [ ] All overlays build successfully
- [ ] All manifests pass kubeconform
- [ ] Image tags valid semver or digest
- [ ] No schema violations
- [ ] Environment overlays complete

## Tools

- Kustomize
- Helm
- kubeconform
- yq

## Output Format

```json
{
  "skill": "gitops-manifest-validation",
  "status": "pass | fail",
  "overlays": {
    "dev": {"build": "pass", "schema": "pass"},
    "staging": {"build": "pass", "schema": "pass"},
    "prod": {"build": "pass", "schema": "pass"}
  },
  "total_manifests": 25,
  "valid": 25,
  "invalid": 0
}
```

## Success Criteria

- All manifests valid
- No schema violations
- No missing images or tags
